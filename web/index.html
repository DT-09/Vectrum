01 / THE ENGINE

Not another diff viewer.

VECTRUM turns two contract snapshots into a structured compatibility assessment. Explicit rules classify known risks; uncertain changes remain review-required.

01

Structural change

Identify additions, removals and modified contract definitions.

02

Compatibility

Separate breaking changes from compatible additions and uncertain modifications.

03

Downstream impact

Traverse declared dependencies to surface direct and transitive consumers.

04

Evidence

Return machine-readable findings with before/after context and explicit limitations.

02 / THE METHOD

Evidence before assurance.

Normalize. Compare. Classify. Trace. Report.

$ vectrum compare \
  --baseline old.json \
  --candidate new.json \
  --graph dependencies.json

→ normalized contract snapshots
→ deterministic structural analysis
→ dependency impact traversal
→ evidence-backed JSON report
